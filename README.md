Most of my contributions on GitHub are to [Endless Sky](https://github.com/endless-sky/endless-sky).  
If you play that game, you might be interested in my plugin, [Rumskib](https://github.com/TheGiraffe3/rumskib).  
I maintain a few other Endless Sky-related projects/plugins: [zuckung-scripts-online](https://github.com/TheGiraffe3/zuckung-scripts-online) (a repository that lets you create compatibility plugins), [Omnis](https://github.com/EndlessSkyCommunity/-Omnis) (all-content plugin), and the [Endless Sky Creator's Handbook](https://github.com/TheGiraffe3/Endless-Sky-Creators-Handbook/wiki) (unofficial contributing guide + lore documents).
