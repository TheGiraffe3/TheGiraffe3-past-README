The majority of my contributions on GitHub are to [Endless Sky](https://github.com/endless-sky/endless-sky), where I create and review content pull requests.
If you play that game, you might be interested in [Rumskib](https://github.com/TheGiraffe3/rumskib) or the [Jibauni](https://github.com/TheGiraffe3/Jibauni) (although note that the Jibauni aren't up-to-date or very well balanced yet).
I also maintain a few other Endless Sky-related projects/plugins: [zuckung-scripts-online](https://github.com/TheGiraffe3/zuckung-scripts-online) (a repository that lets you create compatibility plugins), [Omnis](https://github.com/EndlessSkyCommunity/-Omnis) (an all-content plugin), and the [Endless Sky Creator's Handbook](https://github.com/TheGiraffe3/Endless-Sky-Creators-Handbook/wiki) (unofficial contributing guide + lore documents).

[BZFlag](https://github.com/BZFlag-Dev/bzflag) is another video game I've contributed to, although not in a major way. I've also written several `bzfs` plugins.

I'm the creator of [Templum Serpentis](https://github.com/TheGiraffe3/templum-serpentis), a pixel art roguelike involving serpents.
